# Snaptube Web

تطبيق ويب فاخر لتحميل الفيديوهات والموسيقى من الإنترنت، مصمم بأداء عالي وواجهة مستخدم أنيقة، جاهز للرفع على **Vercel**.

## المميزات

| المميزة | الوصف |
|---------|-------|
| 🎨 تصميم فاخر | واجهة مستخدم حديثة بتأثيرات الزجاج والدرجات اللونية الفاخرة |
| ⚡ أداء عالي | مبني على Next.js 14 مع تحسينات الأداء المدمجة من Vercel |
| 🌐 دعم العربية | اتجاه RTL كامل ودعم اللغة العربية افتراضياً |
| 📱 متجاوب | يعمل على جميع الشاشات من الجوال إلى سطح المكتب |
| 🎯 أكثر من 20 موقع | يوتيوب، فيسبوك، إنستغرام، تيك توك، أنغامي، دايليموشن، وغيرها |
| 🎛 جودة قابلة للتخصيص | 1080p, 720p, 480p, 360p مع صيغ MP4 و MP3 |

## الهيكل التقني

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (لحركة العناصر)
- **Lucide React** (الأيقونات)
- **Vercel** (للنشر)

## كيفية التشغيل محلياً

```bash
# Clone أو تحميل المشروع
cd snaptube-web

# تثبيت الاعتمادات
npm install

# تشغيل في وضع التطوير
npm run dev

# البناء للإنتاج
npm run build

# تشغيل نسخة الإنتاج محلياً
npm start
```

## النشر على Vercel

### الطريقة الأولى (السريعة)
1. ارفع المشروع إلى مستودع GitHub
2. سجل دخول إلى [Vercel](https://vercel.com)
3. انقر "Add New Project" واختر مستودع المشروع
4. اضبط الإعدادات التالية:
   - Framework Preset: **Next.js**
   - Build Command: `npm run build`
   - Dev Command: `npm run dev`
   - Install Command: `npm install`
5. انقر "Deploy"

### الطريقة الثانية (عبر CLI)
```bash
npm i -g vercel
vercel login
vercel --prod
```

## ملفات التكوين

| الملف | الغرض |
|-------|-------|
| `next.config.js` | إعدادات Next.js والصور والرؤوس الأمنية |
| `tailwind.config.js` | نظام التصميم (الألوان، الخطوط، التخفيظ) |
| `vercel.json` | إعدادات النشر على Vercel والرؤوس الأمنية |
| `tsconfig.json` | إعدادات TypeScript |
| `postcss.config.js` | إعدادات PostCSS لـ Tailwind |
